# Stackshot

Signed, notarized macOS builds of Stackshot, and the update feed the app checks.

**Download:** [the latest release](https://github.com/hannahmwright/stackshot-releases/releases/latest). Open the `.dmg` and drag Stackshot to Applications.

Requires macOS 15 or later. Stackshot updates itself: it checks for new versions daily, and you can choose **Check for Updates…** from its menu bar icon.
